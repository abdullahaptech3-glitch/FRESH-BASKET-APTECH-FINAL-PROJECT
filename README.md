# FreshBasket 🛒

**FreshBasket** is a premium, fully interactive online grocery e-commerce web application built as an Academic Capstone Project for Aptech. It simulates a farm-to-table organic grocery experience across major hubs in Pakistan, including Karachi, Lahore, and Islamabad.

🌐 Live Demo: (https://freshbasketaptech.netlify.app/)

---

## ✨ Features
* **Interactive Shopping Cart:** Add or remove farm-fresh fruits, vegetables, dairy, and bundles with live subtotal, shipping, and discount calculations.
* **Dynamic Promo System:** Built-in checkout logic that processes active promo codes (like `FRESH20` for 20% off).
* **Simulated Delivery Slot Checker:** Users can select their specific local area (e.g., DHA, Clifton, Gulberg, F-7) to check real-time express delivery windows.
* **Chef's Curated Bundles:** 1-click addition of comprehensive meal ingredient bundles (like the Desi Biryani Grocery Bundle).
* **Fully Responsive UI:** Optimized for a seamless shopping experience across mobile, tablet, and desktop viewports.
